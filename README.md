# sd-webui-autoskip
 Extension for SD WebUI (A1111, Forge, Neo, etc.) for automatically skipping generation at the defined step.
## Installation
Open WebUI > Go to Install from URL tab > Paste this repo's URL into the first field > Click Install

Or go to your WebUI folder and manually clone this repo into your extensions folder:

`git clone "https://github.com/muerrilla/sd-webui-autoskip" extensions/sd-webui-autoskip`
